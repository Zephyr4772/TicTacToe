# No-Draw Tic-Tac-Toe 🎮

A minimalistic browser-based Tic-Tac-Toe game — but with a twist:  
**draws are impossible**. Someone always wins.

## 🔹 Features

- Clean, lightweight UI
- Player vs Player mode
- No draws — every game ends with a winner
- Fully browser-based (HTML, CSS, JS)

## 🔧 How to Play

1. Clone or download the repository.
2. Open `Index.html` in your browser.
3. Take turns placing X and O.
4. Play until someone wins — because there’s no draw logic 😈
